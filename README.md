# Saturis

Website and legal pages for **Saturis**, an offline pool and spa water-chemistry app
for Android.

- [Privacy policy](https://jaredstaniland-wq.github.io/saturis/privacy.html)

- [Help and support](https://jaredstaniland-wq.github.io/saturis/support.html)

Support: saturisapp@gmail.com

This repository contains only static pages, served by GitHub Pages. It exists because
Google Play requires a publicly reachable privacy policy. The application source is
not published here.
